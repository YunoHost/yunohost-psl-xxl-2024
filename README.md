# Premier Samedi du Libre XXL 2024

Cette présentation, un peu moins technique, a été faite lors du PSL XXL de Novembre 2024 à la Cité des Sciences et de l'Industrie à Paris.

Les sources sont dans le fichier `.md`, au format RevealJS pour être traitées par HedgeDoc et pouvoir en générer une page HTML contenant le diaporama.
